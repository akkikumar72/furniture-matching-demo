# Add Form to the portfolio

The pack is ready for the existing Akkivo-style grid and case study. The presentation uses Urbanist, lime backgrounds and rounded white surfaces. The Form app itself is unchanged.

## Paste into a task in akash-portfolio

```text
Add Form as one new grid tile and case study immediately after Akkivo in this portfolio.

Use the prepared pack at:
docs/portfolio/form in a local checkout of furniture-matching-demo

Read IMPLEMENTATION-PROMPT.md and DESIGN-SYSTEM.md in that folder and implement the handoff end to end. Use the supplied content/form.ts and copy all 13 WebP images into public/assets/. Register Form in content/case-studies.ts and content/gallery.ts. Display the six core images in the default case study.

Match Akkivo's existing modal and three sections: The idea, The workspace and How it’s built. Preserve the Urbanist/lime styling already embedded in the images. Reuse the existing components and dependencies. Keep the portfolio’s global typography and live Form app unchanged.

Preserve existing uncommitted work. Use the supplied factual copy without invented metrics or testimonials. Check desktop and mobile crops, accessibility and modal behaviour. Run the repository's content audit and verification checks. Show the finished grid tile and case study. Do not commit, push or deploy.
```
